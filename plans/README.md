## Findings considered and rejected

- macOS vibrancy or a glass titlebar: `DESIGN.md` §7 bans glassmorphism as default chrome. The overlay titlebar is already the native chrome.
- A new palette, font, or "more modern" skin: `DESIGN.md` already specifies zinc chrome, Gale Teal, and Doubloon. Restyling would violate the design system.
- Rewriting `SyncPanel.tsx` out of its centered dialog: the file is 1271 lines and the panel is a setup flow, not the daily file list. Not part of this desktop-chrome pass.
- Session tabs or two live connections: `App.tsx` holds one session, and editor watches are session-scoped. That is a product bet, not a chrome fix.
- Refresh on Cmd+R, or Back on Alt+Left: the webview already uses those. The plans deliberately omit them.
- Removing the checkbox column: header select-all and the explicit toggle gesture still need it. Row click is the primary selection path instead.
